# SOURCES
Cette version est construite à partir des deux PDF fournis : le planning individuel Jury CANAL+ (`0.pdf`) et le Guide pratique officiel du Festival (`26-07-24-fcadguide...pdf`).

CROISEMENT : une projection présente dans les deux sources n'est pas dupliquée dans le planning : le bloc Jury est l'occurrence obligatoire et le programme du Guide fournit les autres séances disponibles. Les éléments uniquement présents dans le PDF Jury (réunions, cabines, rencontre Siri Hustvedt, transports, cérémonies, dîners et soirées) sont intégrés comme contraintes Jury.

Priorité : pour les blocs du planning Jury, les horaires du PDF Jury sont conservés. Les séances alternatives proviennent du Guide. `Gremlins, l’Amérique parasitée` et `American Nightmare` sont traités comme une seule œuvre.
