# SOURCES — v0.3

## PDF Jury
`0.pdf` — rubrique « VOTRE PLANNING ».

Seuls les éléments listés dans cette rubrique sont intégrés comme contraintes fixes du planning Jury : transports, check-in, cérémonies/projections prévues au Jury, réunion, délibérations, palmarès, dîners et soirées.

Les inaugurations de cabines de plage ne sont PAS des contraintes Jury dans cette version : elles figurent dans le Guide du Festival, pas dans la rubrique « VOTRE PLANNING » du PDF Jury.

## Guide officiel
`26-07-24-fcadguideprat-web-page-105x148-1.pdf`.

Il fournit le programme public des projections et les horaires/salles.

## Croisement
Quand une projection figure dans les deux documents, elle est représentée une seule fois dans le planning obligatoire, avec l'horaire du PDF Jury pour la contrainte personnelle. Les autres séances du même film restent disponibles depuis le programme officiel.

Cas particulier : `Gremlins, l’Amérique parasitée` / `American Nightmare` = même œuvre.

Cas particulier : certains blocs Jury incluent cérémonie + projection et ont donc une durée différente de la seule durée du film dans le Guide. Le bloc Jury est conservé comme contrainte.
